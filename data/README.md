# Dataset

This directory holds the data used by TrackGuard.

## Non-private data

- `toy/` — a small synthetic sample for smoke tests.
- `dataset_info.json` — generated by `scripts/register_recovery_dataset.py`; registers the recovery MCQ dataset for LLaMA-Factory.

## Recovery MCQ dataset (PRIVATE — not released)

The memory-guided VLM recovery module is fine-tuned and evaluated on a proprietary
multiple-choice dataset. This data is **not** included in the repository and must be
built locally. The training and evaluation scripts expect the following layout:

```text
data/recovery_mcq_dataset/
├── llama_factory/
│   ├── train.json
│   ├── val.json
│   └── test.json
└── images/
    ├── train/
    ├── val/
    └── test/
```

### Sample format

Each record is one recovery multiple-choice question in LLaMA-Factory sharegpt
multi-image format, with two full-frame images:

- `images[0]` — the current frame, with the query target drawn as a red box labelled `Q`.
- `images[1]` — a history frame, with candidate targets drawn as labelled boxes `A`, `B`, `C`, `D`.

The prompt contains **no pixel coordinates** (visual / set-of-marks prompting). The
model must answer which labelled history box (`A`/`B`/`C`/`D`) corresponds to the
query `Q` box, i.e. which candidate is the same identity across the two frames.

```json
{
  "messages": [
    {"role": "user", "content": "<image><image>\n<question text, no coordinates>"},
    {"role": "assistant", "content": "B"}
  ],
  "images": [
    "data/recovery_mcq_dataset/images/train/xxx_current.jpg",
    "data/recovery_mcq_dataset/images/train/xxx_history.jpg"
  ],
  "_meta": {
    "answer": "B",
    "n_options": 4,
    "sample_id": "seq01_f0123_id7",
    "sequence": "V001",
    "frame": 123,
    "history_frame": 98,
    "gt_id": 7
  }
}
```

### Field reference

| Field | Type | Description |
|---|---|---|
| `messages` | list | sharegpt turns; the user turn has two `<image>` placeholders, the assistant turn is the answer letter |
| `images` | list[str] | exactly two image paths: current frame then history frame |
| `_meta.answer` | str | ground-truth option letter (`A`..`D`); used as the label at evaluation time |
| `_meta.n_options` | int | number of candidate boxes in the history frame (used for per-bucket metrics and the random baseline) |
| `_meta.sample_id` | str | unique sample identifier |
| `_meta.sequence` | str | source sequence id |
| `_meta.frame` | int | current-frame index |
| `_meta.history_frame` | int | history-frame index |
| `_meta.gt_id` | int | ground-truth track id of the query target |

`_meta` is optional for training but required for the full per-bucket metrics
reported by the evaluation scripts.

### Registering and using the data

```bash
python scripts/register_recovery_dataset.py --dataset_dir data/recovery_mcq_dataset
```

This writes `data/dataset_info.json` with entries `recovery_mcq_train`,
`recovery_mcq_val`, and `recovery_mcq_test`, which the fine-tuning configs
(`configs/recovery_vlm_lora.yaml`, `configs/recovery_vlm_qlora.yaml`) load via
`dataset_dir=data`.
